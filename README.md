# 🕵️ Fake Job Post Predector

An AI-powered web application that detects whether a job posting is **Fake** or **Genuine** using Machine Learning and Natural Language Processing.

---

## 🚀 Live Demo
👉 Deployed on Streamlit Cloud (Free)

---

## 📌 Features
- Detects fake job postings from text
- Simple and user-friendly interface
- AI/ML-based text classification
- Confidence score for predictions
- Fully deployed web application

---

## 🧠 How It Works
1. User pastes a job description
2. Text is processed using NLP techniques
3. A trained ML model classifies the job post
4. Result is shown as **Fake** or **Genuine**
